## 2. Casi NUOVI non coperti da `math.fsum` (riferimento `fractions.Fraction`)

Script riproducibile: [`verifica124_sonde_e_mutanti.py`](verifica124_sonde_e_mutanti.py).

`math.fsum` garantisce la **somma esatta arrotondata una sola volta a `float64`** (e quindi elimina la dipendenza dalla versione di Python 3.9 vs ≥ 3.12). Tuttavia, nel modulo le decisioni confrontano `math.fsum(xs) / k` (due arrotondamenti: prima `float64` sulla somma in scala `O(k)`, poi la divisione `/ k` in `float64`), anziché confrontare la media razionale esatta `sum(Fraction.from_float(x)) / k` (o `sum(Fraction) ≷ Fraction(soglia) * k`). Anche `test_verdetto_d31.py:682-685` (`media_esatta`) confronta contro `float(sum(Fraction(x))) / k`, ereditando lo stesso doppio arrotondamento.

### 2.1 Divergenze decisionali riprodotte

1. **`D1` — Falso rigetto in `screening()` (`verdetto_d31.py:230-231`), soglia di default `+0.25 R`, `k = 300`:**
   - Input: `299 × (0.25, 1)` + `1 × (0.25 + 2^-48, 1)` (`0.25 + 2^-48` è rappresentabile esattamente in `float64`).
   - Riferimento esatto `Fraction`: somma `75 + 2^-48`, media `0.25 + 2^-48 / 300 > 0.25` → **supera il criterio di media (`True`)**.
   - Modulo (`math.fsum`): poiché `ULP(75.0) = 2^-46`, `math.fsum` arrotonda `75 + 2^-48` a `75.0` → `s["media"] = 75.0 / 300 = 0.25` → **respinta (`False`, `media 0.2500 non > +0,25 R`)**.
2. **`D2` — Veto mancato in `veto_blocchi()` (`verdetto_d31.py:263, 267`), soglia di default `-0.25 R`, `k = 250`:**
   - Input: `249 × (-0.25, 1)` + `1 × (-0.25 - 2^-49, 1)` (`-0.25 - 2^-49` è rappresentabile esattamente in `float64`).
   - Riferimento esatto `Fraction`: somma `-62.5 - 2^-49`, media `-0.25 - 2^-49 / 250 < -0.25` → **`fallito` (veto scattato)**.
   - Modulo (`math.fsum`): poiché `ULP(62.5) = 2^-47`, `math.fsum` arrotonda `-62.5 - 2^-49` a `-62.5` → `m = -62.5 / 250 = -0.25` → **`superato` (veto mancato)**.
3. **`D3` — Falso veto su serie COSTANTE per doppio arrotondamento `fsum([x]*k) / k < x` (`verdetto_d31.py:263, 267`, `k` non potenza di 2):**
   - Su una serie costante di appena **`k = 3`** sedute tutte uguali alla soglia `soglia = x` (es. `[( -0.4, 1 )] * 3`, `soglia = -0.4`), la media razionale esatta è esattamente `x` (atteso: **`superato`**, perché l'uguaglianza non fa scattare il veto).
   - Invece `math.fsum([-0.4, -0.4, -0.4])` arrotonda a `-1.2000000000000002`, e la divisione per `3` dà `-0.40000000000000008 < -0.4` → **`esito = "fallito"` (falso veto)**.
   - Nella scansione di `verifica124_sonde_e_mutanti.py` (`k ∈ {3, 7, 29, 49, 250, 251, 300}`, `x` a passo `0.001` in `[-0.4, 0.4]` + razionali semplici) sono emersi **242 casi** con `math.fsum([x]*k) / k < x` (es. `k = 3`, `x ∈ {-0.400, -0.396, -0.392, -0.388, -0.384, -0.380, ...}`).
